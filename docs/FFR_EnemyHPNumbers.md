# FFR_EnemyHPNumbers

## Overview
**FFR_EnemyHPNumbers** adds exact numerical health displays and stagger progress values directly over enemy health bars in *Final Fantasy Resonance*.

---

## Features
* **Exact Numerical Health**: Replaces ambiguous health bars with exact current/max numerical values (e.g., `14,250 / 25,000 HP`).
* **Percentage & Stagger Meter Clarity**: Shows exact percentage values for enemy stagger buildup.
* **Readable Font & Contrast**: Clear, high-contrast text designed to remain legible against varied battle backgrounds and special effects.

---

## File Structure
* `Scripts/main.lua`: Entity health scraper and screen-space widget renderer.
